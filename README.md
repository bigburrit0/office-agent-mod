# tablero-oficina

Mod de Claude Code: panel de subagentes estilo oficina 8 bits (comando /oficina).
La fuente de verdad del mod es `mod\`. Aceptación, desde esta carpeta:
- `claude.exe plugin validate mod` -> código 0
- `claude.exe plugin test mod` -> 0 fail, mismos pass que el mod original
- buscar `command: 'tablero'` en `mod\hooks\register.tsx` -> sin resultados
